# Gerges Faiz — portfolio

Personal portfolio site for Gerges Faiz, Flutter developer. One self-contained `index.html` (inline CSS and JS, English/Arabic toggle).

Live: https://gerges-faiz.vercel.app

## How to edit

1. Edit `index.html` (open it in a browser to preview locally).
2. Commit: `git commit -am "Describe the change"`
3. Push: `git push`

Every push to `main` deploys to production on Vercel automatically (project `gerges-faiz`).
