How I work

I treat a shop's data like money, because it is. Offline first, so a dropped connection never stops a sale. Exact arithmetic, so the drawer matches the report. Tests in CI, so the next release doesn't break last month's invoices.

I write Clean Architecture with BLoC/Cubit, ship to Android, iOS, desktop and web from one codebase, and design for Arabic first when the users read Arabic.
